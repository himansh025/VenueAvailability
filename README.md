# 🏛️ Venue Availability

A web-based platform that helps users **find, book, and manage venues** efficiently — ensuring no double bookings and providing real-time availability. Built using the **MERN Stack (MongoDB, Express, React, Node.js)**.

---
Live Link ---- https://venueify.vercel.app

## 🚀 Features

✅ **Venue Discovery** – Browse available venues by date, time, and category.  
✅ **Real-time Availability** – Prevents double-booking through conflict detection.  
✅ **Booking Management** – Create, view, and cancel bookings easily.  
✅ **Admin Dashboard** – Admins can manage venues, bookings, and user access.  
✅ **Authentication System** – Secure login and registration (JWT + bcrypt).  
✅ **Responsive UI** – Clean and modern interface using React + Tailwind CSS.
